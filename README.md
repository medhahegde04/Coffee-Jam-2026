# Coffee Jam 2026 – The Resting Cup

A cozy 3D cafe game made for [Coffee Jam 2026](https://itch.io/jam/coffee-jam-2026), built solo in Unity over 3-4 days.


## How to Play

1. Click a cup to determine the drink.
2. Click the espresso machine to brew it.
3. Click a dessert if the order calls for one.
4. Hit **Serve** to complete the order, or **Trash** to discard and start over.
5. Keep orders coming for as long as you can – score goes up for correct orders, down for wrong or missed ones.
